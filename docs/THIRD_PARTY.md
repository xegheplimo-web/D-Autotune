# Dependencies & commercial usage

- **Google Oboe 1.11.0** (`com.google.oboe:oboe:1.11.0`): Apache License 2.0, via Google Maven and Prefab; https://github.com/google/oboe/blob/main/LICENSE. Add its applicable copyright and license text to any binary distribution / notices as required.
- **Android SDK, NDK, Kotlin, Gradle**: development toolchains, not vendored here. Review each license and distribution requirement separately.
- **D-Autotune's own source code**: MIT (see `LICENSE`). No other third-party DSP/Auto-Tune implementation copied.
- Commercial release also requires privacy disclosures (microphone), permission rationale, safety review, real-device tests, Play policy compliance, and branding/trademark checks. "Auto-Tune" may be a trademark; request a brand clearance before using it commercially in the app/store name. A more generic name such as `D-Vocal Tune` may be safer.

## Trademark evidence (preliminary research, 2026-10-31 — Hermes; NOT legal advice; owner decides)

Sources: antarestech.com/press + /about + /es + /ko (retrieved 2026-10-31), trademarkelite.com/trademark/trademark-detail/99040050/AUTOTUNE.

- **Antares' own claims**: `AutoTune®`, `Auto-Tune®`, `Antares®`, `AVOX®`, `Harmony Engine®`, `Mic Mod®`, `Solid-Tune®` are registered trademarks of Antares Audio Technologies (stated on every Antares web page footer).
- **Word mark "AUTOTUNE"** — USPTO Serial 99040050, filed 2025-02-13 by Antares Audio Technologies, LLC (Santa Cruz, CA). Status: **NOTICE OF ALLOWANCE - ISSUED** (status date 2026-05-12). **Deadline: 2026-11-12** for Statement of Use — i.e. the mark is on track to be REGISTERED within ~2 weeks of this date. Classes: 9 (computer software — "Downloadable software for use in music and audio production", "measurement, manipulation and alteration of digital audio information"), 41/42 (entertainment + software services). Principal Register.
- **Risk assessment for "D-Autotune"**: the dominant portion ("Autotune") is the protected mark, in the same goods/services class (audio software). Publicly using "D-Autotune" as an app/store name = high likelihood of confusion with Antares' AUTOTUNE application. The "autotune" generic-verb defense is NOT safe for a product name (mark remains registered/protectable in class 9; Antares is actively maintaining filings).
- **Internal name is unaffected**: "D-Autotune" as an internal project name (repo, docs, control plane) is not a public-facing use. Per directive §12 the owner must decide the release name BEFORE any store listing. This evidence exists so that decision is made on data, not assumption.
