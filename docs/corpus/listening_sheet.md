Scales:

- **Naturalness**: 1 = clearly synthetic/metallic; 2 = obviously
  processed; 3 = mildly processed but plausible; 4 = natural with minor
  doubts; 5 = indistinguishable from an unprocessed take.
- **Audible artifacts**: clicks, pumping/level breathing, warble,
  robotic/metallic timbre, doubled or smeared onsets, pitch wobble.
  Name the file slot (`A`/`B`) and timestamp if possible.
- **Preference**: which file you would keep for a demo — `A`, `B`, or
  `none` — identical/indistinguishable.
